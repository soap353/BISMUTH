# BISMUTH for Linux (Portable)

Modern, high-performance game server hosting platform for **Minecraft (Java & Bedrock)** and **Rust Dedicated Server**.

---

##  Quick Start on Linux

### 1. Prerequisites
Ensure you have **Node.js** (v18, v20, or v22) and **npm** installed on your system:
- **Ubuntu / Debian / Mint**:
  ```bash
  sudo apt update && sudo apt install -y nodejs npm
  ```
- **Fedora / RHEL**:
  ```bash
  sudo dnf install -y nodejs npm
  ```
- **Arch Linux / Manjaro**:
  ```bash
  sudo pacman -S nodejs npm
  ```

---

### 2. Launching BISMUTH
1. Extract this zip file anywhere on your system.
2. Open a terminal inside the extracted folder and run:
   ```bash
   chmod +x start-bismuth.sh
   ./start-bismuth.sh
   ```
3. BISMUTH will install local dependencies on first launch and open the desktop application.
