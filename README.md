# BISMUTH

BISMUTH is a desktop application for hosting and managing Minecraft and Rust dedicated servers easily and locally. It handles automated server installation, process lifecycle management, UPnP port forwarding, firewall security, backups, and local-network remote administration via a mobile-optimized web UI.

## Supported Servers

- **Minecraft Java Edition**:
- **Minecraft Bedrock Edition**
- **Rust**

## Features

- **Remote Access & Mobile Web UI**: Responsive LAN web interface with Apple HIG touch navigation, server switching drawer, and standardized mobile layouts for phones and tablets.
- **Networking & UPnP**: Automatic UPnP port forwarding via `nat-upnp`, local network IP detection, and manual port configuration.
- **Player Analytics**: Player session tracking, playtime, in-game statistics, and CSV export.
- **Backups & Snapshots**: 1-click snapshot creation (ZIP) and world dimension export.

## Download

### Windows
1. Download [`BISMUTH-Portable.zip`](https://github.com/soap353/BISMUTH/releases/latest/download/BISMUTH-Portable.zip) or [`BISMUTH.exe`](https://github.com/soap353/BISMUTH/releases/latest/download/BISMUTH.exe).
2. Extract the archive.
3. Run `BISMUTH.exe` (requires Node.js LTS).

### Linux
1. Download [`BISMUTH-Linux-Portable.zip`](https://github.com/soap353/BISMUTH/releases/latest/download/BISMUTH-Linux-Portable.zip).
2. Extract the archive.
3. Run `./start-bismuth.sh` or launch `BISMUTH-Linux.desktop`.
